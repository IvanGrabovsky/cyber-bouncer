# 🕶️ Cyber Bouncer AI (Нео-Київ 2077)

> **Практичне завдання з JavaScript:** Умовні конструкції (`if/else`), логічні оператори (`&&`, `||`, `!`) та оператори порівняння (`===`, `>=`, `<`).

## 🌆 Сюжет місії

Рік 2077. Нео-Київ освітлений неоновими вивісками хмарочосів. Найгарячіше місце міста — підземний кібер-клуб **«Neon Pulse»**.
На вході стоїть автономний дроїд-фейсконтроль, але його мікросхеми пошкодив цифровий вірус!

Керівництво клубу найняло **тебе**, щоб відновити алгоритми штучного інтелекту дроїда:
1. Перевіряти право на вхід відвідувачів.
2. Розраховувати вартість вхідного квитка з урахуванням знижок і VIP-статусу.
3. Розподіляти гостей за зонами доступу згідно з їхнім кібер-балансом.

## 📋 Завдання

Відкрийте файл [`src/bouncer.js`](src/bouncer.js) та реалізуйте три функції:

### 1. `canEnter(age, hasTicket, isVip, isBanned)`
- Якщо відвідувач занесений у чорний список (`isBanned === true`) — вхід **заборонено** (`false`) за будь-яких обставин!
- Відвідувачу має бути не менше 18 років (`age >= 18`).
- Якщо вік дозволяє і людина не в чорному списку, вона може пройти, якщо:
  - у неї є квиток (`hasTicket === true`) **АБО**
  - вона має VIP-статус (`isVip === true`).

### 2. `calculateTicketPrice(basePrice, isStudent, isVip, promoCode)`
- Якщо гість VIP (`isVip === true`) — квиток **безкоштовний** (`0`).
- Якщо діє промокод `'NEON2077'` (`promoCode === 'NEON2077'`) — знижка **50%** від базової ціни.
- Якщо гість студент (`isStudent === true`) — знижка **30%** від базової ціни.
- В інших випадках — повна ціна `basePrice`.
*(Пріоритет знижок: VIP > Промокод > Студент. Знижки не сумуються).*

### 3. `getAccessZone(balance)`
- Якщо `balance` не є числом або менше 0 — повертає `'Denied'`.
- Менше 100 кредитів (`< 100`) — `'Street'`.
- Від 100 до 499 включно — `'Standard'`.
- Від 500 до 1999 включно — `'VIP Lounge'`.
- 2000 і більше — `'Cyber Penthouse'`.

## 🛠️ Як працювати з проєктом

### 1. Встановлення залежностей
```bash
npm install
```

### 2. Запуск тестів
```bash
npm test
```
*Або запустіть у режимі live-watch, щоб бачити результат при кожному збереженні:*
```bash
npm run test:watch
```

## 🚀 Як здати роботу через GitHub

1. Зробіть **Fork** цього репозиторію у свій GitHub-акаунт.
2. Склонуйте ваш форк на комп'ютер:
   ```bash
   git clone <посилання-на-ваш-fork>
   ```
3. Виконайте завдання у файлі `src/bouncer.js`.
4. Перевірте, що всі тести проходять локально (`npm test`).
5. Збережіть і відправте код на GitHub:
   ```bash
   git add .
   git commit -m "feat: complete cyber bouncer tasks"
   git push origin main
   ```
6. Перейдіть на GitHub у вкладку **Actions** вашого репозиторію — там автоматично запуститься перевірка! Якщо все правильно — з'явиться зелена галочка ✅.
